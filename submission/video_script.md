# Guion de Video Demo para OpenAI App Review (DataCanvas)
**Duración objetivo:** 75 segundos.

---

### Segmento 1: Introducción y Descubrimiento (0:00 - 0:15)
- **Visual:** El usuario en ChatGPT abre la barra lateral y selecciona el plugin "DataCanvas".
- **Audio/Voz en off:** "DataCanvas transforms raw spreadsheets and CSVs into interactive, executive-grade dashboards directly within ChatGPT."

### Segmento 2: Activación y Panel en Conversación (0:15 - 0:40)
- **Visual:** El usuario pega un conjunto de datos de ventas trimestrales y pide: *"Armame un dashboard visual de este CSV con gráficos interactivos y métricas"*.
- **Acción:** ChatGPT llama a la tool `datacanvas_render_dashboard`. Se despliega inmediatamente el **Conversation Panel** interactivo al lado derecho del chat con ECharts, KPI cards y selectores.
- **Audio:** "The model parses data semantics and renders a native live inspector panel side-by-side with the chat."

### Segmento 3: Interactividad y Filtros en Tiempo Real (0:40 - 1:00)
- **Visual:** El usuario cambia el selector de tipo de gráfico de 'Barras' a 'Línea de Tendencia' y luego a 'Donut'. Realiza una búsqueda en la caja de filtro y cambia el tema de Dark a Light mode.
- **Audio:** "Users can dynamically filter categories, toggle chart types, and inspect KPIs in real-time, powered by high-speed client-side WASM computation."

### Segmento 4: Exportación Ejecutiva y Monetización Externa (1:00 - 1:15)
- **Visual:** El usuario hace clic en "Exportar PDF" o "DataCanvas Pro". Aparece el modal informativo. El usuario hace clic en "Ir a Checkout Seguro" y se abre una pestaña externa hacia `https://datacanvas.ranuk.dev/checkout`.
- **Audio:** "To unlock unbranded, publication-quality executive reports or database integrations, users smoothly upgrade via merchant-hosted secure checkout."
